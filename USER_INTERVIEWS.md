# User Interviews

## Interview 1 — R.K., CTO, 8-person dev agency (bootstrapped)
**Date:** Day 4 · 13-minute voice call

Pays for Cursor Business (6 seats), Claude Pro (personal), OpenAI API shared informally.

**Quotes:**
> "I see the Anthropic charge and the OpenAI charge on my Amex every month and honestly have no idea which engineer is burning through the API credits. It's a black box."
> "The engineers would revolt if I switched them off Cursor. They'd probably quit before going back to Copilot."
> "I don't need to save $200 a month. I need to know if I'm paying for the right things. That's different."

**Most surprising:** Not motivated by savings at all. Wanted *justifiability* — being able to tell a client "we use these AI tools and here's why." The audit as a rationale for your stack, not just a savings calculator.

**What it changed:** Added "right-sized for your team" framing alongside the savings number. The savings hero stayed but sub-copy now emphasizes tool-fit.

## Interview 2 — A.M., Solo founder, pre-revenue SaaS
**Date:** Day 5 · 12-minute voice note exchange via Indie Hackers DM

Pays for ChatGPT Plus, Claude Pro, Cursor Pro, Windsurf Pro. ~$75/mo total.

**Quotes:**
> "I use all four but if I'm honest I mostly just use Claude and Cursor. The other two I keep 'just in case' which is dumb."
> "I've been meaning to cancel Windsurf for like 3 months. I just forget until the charge shows up."
> "I'd use a tool like this but only if it tells me something I don't already know."

**Most surprising:** Already knew he was overpaying but hadn't acted. The gap between knowing you should cancel and actually cancelling is huge. A dollar figure on the inertia ("you've paid $45 for Windsurf you haven't used") might close it.

**What it changed:** Added overlap detection logic. When someone pays for 2+ coding assistants, the tool explicitly calls it out rather than evaluating each in isolation.

## Interview 3 — S.P., Engineering Manager, 35-person Series A fintech
**Date:** Day 5 · 15-minute call

Pays Copilot Business (12 seats), ChatGPT Team (12 seats), $2k/mo OpenAI API. ~$2,700/mo.

**Quotes:**
> "Every quarter our CFO asks me to justify the AI tool spend. I have the invoices but I don't have a benchmark."
> "Half the team prefers Claude for coding and just uses the web interface, which means we're paying for Copilot seats that aren't being used."
> "The API spend is what I really want to optimize. The subscriptions I can rationalize. The API is a variable cost I have no intuition for."

**Most surprising:** CFO wants "cost per engineer per month vs companies your size" — not absolute savings. Benchmark mode is the killer feature for this persona.

**What it changed:** Added cost-per-developer display on results page. Moved benchmark mode to top of Week 2 feature list. Made API optimization recommendations more specific.
